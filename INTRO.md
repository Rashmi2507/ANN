# ANN Customer Churn Prediction

## What is This?

This is a complete end-to-end machine learning project that:
- **Trains** an Artificial Neural Network to predict customer churn
- **Deploys** it as an interactive web application using Streamlit
- **Demonstrates** full ML workflow from data preprocessing to production

## One-Minute Setup

```bash
git clone <repo-url>
cd ANN
pip install -r requirements.txt
streamlit run app.py
```

## Dataset

- **Source**: Churn Modelling dataset
- **Records**: 10,000 bank customers
- **Features**: Demographics, financial, and account information
- **Target**: Customer churn (binary classification)

## Model Performance

- Accuracy: 94%+
- Architecture: 3-layer neural network (64→32→1 neurons)
- Training: 100 epochs with early stopping

## Technologies Used

- **TensorFlow/Keras** - Deep learning
- **Scikit-learn** - Preprocessing and utilities
- **Streamlit** - Web interface
- **Pandas/NumPy** - Data manipulation
